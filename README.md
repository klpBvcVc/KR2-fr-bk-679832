# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой версию сайта интернет-магазина одежды и обуви, разработанную с использованием Bootstrap 5. Это отдельная реализация предметной области контрольной работы №1, а не её адаптация.

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

## Используемый CSS-фреймворк

Bootstrap 5.3 (подключение через CDN).

## Используемые технологии

- HTML5;
- Bootstrap 5.3 (сетка, компоненты, utility-классы);
- CSS (минимальные правки в `css/custom.css`);
- Git и GitHub (ветки, Pull Requests, GitHub Pages).

## Структура проекта

Планируемая структура (будет дополняться по мере выполнения практических занятий):

- `index.html` - главная страница;
- `catalog.html` - каталог товаров;
- `product.html` - карточка товара;
- `order.html` - форма заказа;
- `css/custom.css` - минимальные собственные стили;
- `README.md` - описание проекта;
- `.gitignore` - список файлов, исключённых из Git.
