# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой версию сайта интернет-магазина одежды и обуви, разработанную с использованием Bootstrap 5. Это отдельная реализация предметной области контрольной работы №1, а не её адаптация: внешний вид и тексты сохранены, а вёрстка заново написана на классах Bootstrap вместо собственного CSS.

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

## Используемый CSS-фреймворк

Bootstrap 5.3.3 (подключение через CDN: CSS в `<head>`, JS Bundle перед `</body>`).

## Используемые технологии

- HTML5;
- Bootstrap 5.3.3 (сетка, компоненты, utility-классы);
- CSS (правки в `css/custom.css`: палитра, шрифты, строгая геометрия без скруглений, тёмная тема);
- JavaScript (`js/main.js`: переключатель темы, кнопка «Наверх», форма и окно быстрого заказа; `js/products.js` и `js/product-page.js`: данные и показ страницы товара; `js/order-page.js`: выбор товара на странице заказа);
- Git и GitHub (ветки, Pull Requests, GitHub Pages).

## Структура проекта

Практика №9:

- `index.html` - главная страница;
- `css/custom.css` - собственные стили поверх Bootstrap;
- `js/main.js` - тема оформления, «Наверх», форма заказа и окно быстрого заказа;
- `images/` - изображения (hero и товары в `images/products/`);
- `README.md` - описание проекта;
- `.gitignore` - список файлов, исключённых из Git.

Практика №10:

- `catalog.html` - каталог товаров с фильтрами;
- `product.html` - страница товара, один файл для всех 20 товаров (`product.html?id=jacket`);
- `order.html` - форма заказа (`order.html?product=jacket` сразу выбирает товар);
- `contacts.html`, `size.html`, `404.html` - дополнительные страницы;
- `js/products.js` - данные 20 товаров и таблицы размеров;
- `js/product-page.js` - показ страницы товара по параметру `id`;
- `js/order-page.js` - выбор товара и хлебная крошка на странице заказа.

## Товары

В магазине 20 товаров, подобранных так, чтобы покрыть разные сочетания: категория (одежда или обувь), цена (до 3 000, от 3 000 до 6 000, от 6 000 руб.) и метка (без метки, «Скидка», «Новинка»).

## Реализованные компоненты

Главная страница (практика №9):

- сетка: `container`, `row`, `col-12 col-md-6 col-lg-4`, `col-lg-5` и `col-lg-7`, отступы между колонками `g-4`;
- `navbar` с адаптивным меню-бургером (`navbar-expand-lg`, `navbar-toggler`, `collapse`);
- `alert` (закрываемая плашка с промокодом, сообщение об отправке заказа);
- `card` с фото и кнопкой, одинаковая высота карточек (`h-100`);
- `badge` («Скидка»);
- `btn` (`btn-primary`, `btn-outline-primary`);
- `modal` быстрого заказа с формой (`form-control`, `form-check form-switch`);
- вкладки `tabs` в блоке преимуществ;
- utility-классы: `d-flex`, `flex-column`, `flex-grow-1`, `gap-*`, `border`, `bg-body-secondary`, `text-body-secondary`, `ratio`, `object-fit-cover`, `position-fixed`.

Страницы практики №10:

- `breadcrumb` (хлебные крошки на всех страницах, кроме главной и 404);
- каталог: `row g-4`, колонки `col-lg-auto` и `col-lg`, карточки `col-12 col-sm-6 col-lg-4`, фильтры на `form-check` (radio) с липкой панелью `sticky-lg-top`;
- `table table-bordered` внутри `table-responsive` (характеристики, сравнение верхней одежды, размеры);
- `accordion`: таблица размеров на странице товара и вопросы «Доставка и оплата» на странице контактов;
- форма заказа: `form-control`, `form-select` с `optgroup`, `form-check form-switch`, `input-group` (поле даты звонка), `form-text`, `alert alert-success` с `role="alert"`;
- `modal` быстрого заказа также на странице контактов;
- `alert alert-warning`, если в адресе страницы товара указан несуществующий `id`.

## Собственные правки

Цель `css/custom.css`: сайт выглядит так же, как в контрольной работе №1. Здесь заданы палитра «бордо и слоновая кость» и тёмная тема (через переменные Bootstrap), шрифты Montserrat и Inter, нулевые скругления, фон-фото и оверлей для hero, оформление вкладок и карточек, кнопка «Наверх», фильтр каталога без JavaScript (правила `:has()`), оформление таблиц и аккордеонов. Всё остальное (сетка, меню, формы, окно, вкладки, таблицы, крошки) работает на стандартных классах Bootstrap.

Отличия от контрольной работы №1 (сделаны осознанно):

- на узких экранах меню сворачивается в бургер (в КР1 его не было);
- карточки «Популярного» идут по три в ряд с 768px, на телефоне в столбик;
- в блоке преимуществ вкладки остаются слева, панель справа на любой ширине, а на экранах уже 768px у вкладок остаются только номера;
- плашка «О магазине» вписана в контейнер и сужается вместе с остальными блоками;
- заголовок «Преимущества концепта» переименован в «Преимущества магазина»;
- из подвала убрана строка «Дисциплина»;
- в магазине 20 товаров вместо 30, поэтому «Похожие товары» берутся только из этих 20 (подбор по группе и цене);
- сравнение верхней одежды (Куртка и Пальто) сделано по трём моделям: Куртка, Пальто, Пуховик (в КР1 третьим был Бомбер, которого в магазине из 20 товаров нет);
- каталог: на экранах уже 992px панель фильтров стоит над товарами, а не слева;
- на странице заказа поле даты звонка собрано в `input-group` с подписью «Дата» (требование методички, в КР1 подписи не было);
- на странице товара, которого нет в списке, показывается сообщение вместо страницы (в КР1 у каждого товара был свой файл);
- в таблицах и аккордеонах возможна разница с КР1 в 1-3 пикселя (другая модель границ у Bootstrap).
